para ejecutar el proyecto se deben hacer estos pasos:

en tu terminal seleccionas la carpeta y despues escribes:

git clone https://github.com/yexp-978/Hackaton.git

Nota importante: deberas tener node js instalado previamente directamente de su pagina oficial:

https://nodejs.org/es

luego escribes en la terminal: 
npm install
para ejecutarlo: 
npm run dev

te arrojara un localhost, ese sera ya la pagina cargada
